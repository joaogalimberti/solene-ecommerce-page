## ✦ Story

Sølene started as a learning project in pure JavaScript and grew into a complete storefront.

```mermaid
graph LR
    A[DOM manipulation<br/>learning project] --> B[React migration<br/>modern architecture]
    B --> C[AI imagery<br/>Gemini]
    C --> D[Production-ready<br/>e-commerce]
```

| Phase | What changed |
|---|---|
| **1. Foundation** | Vanilla JavaScript and CSS, static catalog, basic cart. Focus on event handling, DOM traversal, and state fundamentals |
| **2. Modern stack** | Migration to React with hooks, React Router, and Vite. Added advanced filtering, search, real-time cart, and a responsive design system |
| **3. AI imagery** | Entire catalog photographed by AI for a consistent look |

<br />

## ✦ Features

| | Feature | Description |
|:-:|---|---|
| 🛒 | **Shopping cart** | Real-time management with quantity controls, persistent across navigation |
| 🔍 | **Smart search** | Searches name, description, fabric, and color with instant filtering |
| 🧭 | **Filters and sorting** | Categories (Camisas, Vestidos, Calças, Acessórios), price, name, and relevance |
| 📦 | **Product management** | Size selection, stock tracking, and inventory alerts |
| 💳 | **Checkout ready** | Order summary with line items and automatic totals |
| 🚚 | **Shipping calculator** | Free shipping on orders over R$ 500 |
| 📱 | **Responsive** | Mobile-first, fluid layouts, touch optimized |
| ⚡ | **Performance** | Fast loads and optimized rendering |

**Shopping flow**

```
Browse → Filter and search → Select size → Add to cart → Review order → Shipping → Purchase
```

<details>
<summary><b>Technical details</b></summary>

<br />

- Client-side routing with no page reloads
- Cart state survives navigation
- `useMemo` for optimized rendering
- Lazy-loaded images
- Responsive breakpoints at 640px, 768px, 1024px, and 1400px
- ARIA labels and semantic HTML for accessibility and SEO
- Support for modern browsers (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)

</details>

## ✦ AI product imagery

Every product image was generated and standardized with **Google Gemini (Nano Banana)**, keeping lighting, angle, and style consistent across the whole catalog.

| Benefit | Why it matters |
|---|---|
| **Consistency** | Uniform lighting, framing, and aesthetic |
| **Customization** | Tailored to the brand |
| **Scalability** | New products and variants in minutes |
| **Cost** | No photography setup needed |

**Workflow:** define the aesthetic, write detailed prompts, generate variations, pick the best, then optimize for the web.

**Consistency rules:** neutral background (`#fdfcf9`), soft natural lighting, centered composition, 1:1 aspect ratio, product-focused framing.

<details>
<summary><b>Example prompt</b></summary>

<br />

```
Premium white linen shirt on neutral beige background,
soft natural lighting, centered composition, minimalist
luxury aesthetic, product photography style
```

## ✦ Quick start

```bash
git clone https://github.com/joaogalimberti/solene-ecommerce.git
cd solene-ecommerce
npm install
npm run dev
```

Open **http://localhost:5173**.

| Command | Description |
|---|---|
| `npm run dev` | Starts the dev server with HMR |
| `npm run build` | Builds the optimized production bundle |
| `npm run preview` | Previews the production build locally |
